当前机器是 64 位环境，但传统 BMW Standard Tools/INPA 推荐使用 32 位进程调用：

```text
Api32.dll
```

因此：

- C# 项目建议设置 `PlatformTarget=x86`
- Python 当前是 64 位，不能直接加载 `api32.dll`
- Node.js 当前也是 64 位，不能直接加载 `api32.dll`
- Python/Node 应使用 32 位解释器，或通过 32 位辅助进程进行 IPC 通信

## 9. API 编程实际流程

典型流程：

```text
1. 32 位程序加载 api32.dll
2. apiInit()
3. 指定 SGBD/PRG：mevd1724
4. 调用具体 Job
5. apiResult...() 读取返回值
6. apiEnd()
```

需要区分：

- `mevd1724.prg` 是 DME 诊断 Job 定义
- 它可以用于读取识别信息、状态、故障等
- 它不是单独的刷写程序
- 写入、复位、编程 Job 需要特别谨慎
