## 3. 数据证据链

处理说明：两段 CSV 按时间合并。检测到 3 处采集间隙（50.2 s、64.9 s、9.3 s），其中 23:23:56 有空行，对应电脑熄屏；间隙不参与差分与变化速率。第二段含自动启停与滑行断油（InjQty=0 且 LambdaActual 冲到 >2），已从闭环修正分析中剔除。

### 3.1 最高优先级：LambdaAdaption × EngineLoad / MAF → 类型 1 泄漏

观察到：

- 热车（ECT≥75℃、闭环、非断油）按负荷分箱：
  - 负荷 <15%：Adapt 均值 1.038（+3.80%），n=242
  - 负荷 15–28%：1.010（+1.02%），n=123
  - 负荷 ≥28%：1.010（+0.99%），n=44
- 按 MAF：<12 kg/h 时 +4.56%；70–100 kg/h 时 ?0.27%
- corr(Load, Adapt)=?0.670；corr(MAF, Adapt)=?0.789
- 热怠速 Integrator 均值 1.087（+8.74%），与用户印象中的「约 +8%」更接近短期修正，而非长期 Adapt 的峰值

推断：

- 符合任务文档类型 1：**低负荷修正高，提高转速/负荷后下降**
- 未计量空气在怠速/小空气量时占比大，负荷起来后被计量空气淹没，所以修正回落
- 不是类型 2（全工况稳定正修正），也不是类型 3（高负荷才升高）

可能原因：

- PCV 膜片破裂 / 气门室盖泄漏（与火花塞井机油、历史异味一致）
- 进气歧管、真空管、增压管真空侧泄漏（可能性次之）

验证方法：

1. 冷机目视气门室盖、PCV 阀、第 4 缸火花塞井是否仍有油
2. 进气系统烟测（含气门室盖、PCV 到进气侧）
3. 热怠速喷化油器清洗剂：Integrator 若明显下降，泄漏点在喷雾路径上
4. 记录泄漏修复后再采同一怠速：Adapt 目标应接近 1.00±0.02

### 3.2 LambdaAdaption × 喷油量 → ECU 在真实加浓

观察到：

- 热怠速 InjQty 约 15.8 mg/Hub，估算怠速油耗约 1.9 L/h，同时 Adapt +4.4%、Integrator +8.7%
- 负荷升高后 InjQty 升至约 29 mg/Hub（加速段），但 Adapt 降到约 +1.0%
- 四缸喷油在行驶/加速时几乎完全一致（加速段缸间差 0%）

推断：

- 正修正伴随着怠速喷油增加，是 ECU 闭环补偿，不是 Lambda 数值空转
- 不支持「Adapt 异常但喷油不变 → 先查 Lambda 传感器」这条分支

可能原因：

- 空气侧少计 / 漏气后的正常补偿

验证方法：

- 修复空气泄漏后对比同一怠速 InjQty 是否下降（期望热怠速明显低于 15–16 mg/Hub）

### 3.3 MAF × EngineLoad → 空气计量整体线性

观察到：

- 热车闭环 corr(Load, MAF)=0.953
- 怠速 MAF 约 16.2 kg/h（2.0L 热怠速常见约 12–18 kg/h）
- 负荷 25–30% 时 MAF 约 57 kg/h，与部分负荷相符

推断：

- MAF 没有「负荷高但空气量明显偏低」的形态
- 全局 MAF 低估不是主因（那会接近类型 2）
- 泄漏若发生在 MAF 之后，MAF 读数可以正常，这与类型 1 一致

可能原因：

- MAF 本身大致可信；问题在 MAF 后的未计量空气

验证方法：

- 烟测优先于更换 MAF
- 若烟测阴性，再用已知转速/负荷下的 MAF 标准值或进气压力交叉验证

### 3.4 MAF × Boost × EngineLoad → 本段无法给增压下结论

观察到：

- 环境压力约 1021 hPa
- 本段最高 BoostActual=1143 hPa（23:23:56，负荷 45.3%，车速 57.9 km/h，节气门 27%）
- 热车 corr(Load, Boost)=0.79，corr(MAF, Boost)=0.84
- 无 BoostTarget

推断：

- 涡轮仅进入很浅的增压，属于市区部分负荷正常现象
- 不能评价涡轮效率、放气阀或增压管泄漏
- 该原因目前既不能证实也不能作为油耗解释

验证方法：

- 补采 80–120 km/h 以及一次明确加速，必须同时记 BoostActual 与 BoostTarget

### 3.5 失火 × 喷油 × Lambda → 当前不是油耗主因

观察到：

- 第 4 缸：启动后 2.9 s 计数=1，约到 53 s 仍为 1，之后归零；其后全程 0
- 第 1/2/3 缸全程 0
- 无「每分钟持续爬升」或「每 1000 转持续增加」
- 冷启动该时段四缸喷油基本同量（约 29–34 mg/Hub）

推断：

- 属于冷启动短暂一次，符合任务文档「正常」侧
- 结合火花塞井曾进油，第 4 缸仍是薄弱点，但是**观察项**，不是当前 12.2 L 的解释

可能原因：

- 冷机混合气/点火余量不足；或井内残油影响第 4 缸绝缘（需目视确认是否仍在发生）

验证方法：

- 再记一次冷启动 misfire 计数
- 拆第 4 缸火花塞看电极与井内油迹
- 禁止仅因历史失火而再换一套线圈

### 3.6 ECT × 油耗 → 暖机正常

观察到：

- 0–30 s：27℃
- 约 4 min：60℃
- 间隙后约 6 min：78–80℃
- 约 10 min 起稳定 99–100.5℃，直到记录结束

推断：

- 节温器未卡在 70–80℃
- 冷启动加浓只影响短途，不是热车后持续正修正的原因
- 终点水温 100℃ 对 N20 属常见控制区，不作为故障

验证方法：

- 无需为油耗更换节温器
- 若以后出现风扇常转或水温>110℃，再查电子节温器/散热

### 3.7 VANOS → 无充分异常证据

观察到：

- 冷怠速进气 PWM 锁在 6.3%（N20 冷机锁止常见）
- 热车后进气 PWM 约 29%、排气约 33–35%，本段负荷范围内几乎不随负荷变化（相关约 0）
- 无实际凸轮相位

推断：

- PWM 平台可能只是因为工况窗口太窄（全是市区部分负荷）
- 不能诊断 VANOS 卡滞或配气效率下降

验证方法：

- 下次采集 VANOS 实际角（进/排气）相对目标角
- 在转速/负荷变化时看跟随，而不是只看 PWM 均值

### 3.8 热车怠速细节

观察到：

- RPM 746 vs 目标 702，偏差 +43 r/min，标准差 49（含自动启停恢复瞬间）
- EngineLoad 约 14.2%，节气门约 7.8%
- LambdaActual 0.992 vs Target 0.999，残差均值约 ?0.007
- 怠速缸间喷油相对差均值 2.7%，第 3 缸略高（16.25 vs 15.84 mg/Hub）

推断：

- 怠速偏高 + 短期加浓，与真空泄漏后 ECU 补偿一致
- 第 3 缸喷油略高幅度小，更像补偿或噪声，不像单缸喷油器严重失衡

验证方法：

- 泄漏修复后看怠速是否回到目标附近
- 若修复后第 3 缸仍持续偏高 >5%，再做单缸贡献/喷油器流量验证

### 3.9 冷启动过程

观察到：

- 23:18:54 着车，RPM 1373，目标 1200，ECT 27℃
- t≈6.2 s Integrator 离开 1.00，进入闭环

推断：

- 冷启动控制本身正常：能着车、能进闭环、暖机转速按目标下降
- 正修正是热车后、尤其低负荷才明显，指向热机真空泄漏而非冷启动策略故障

验证方法：

- 用下一次冷启动确认第 4 缸失火是否复现即可

## 4. 维修优先级

### A 类：高概率，修复后市区油耗有望下降

- **PCV / 气门室盖密封（含膜片）**
  - 理由：类型 1 修正 + 热怠速 Integrator 正修正 + 怠速偏高 + 火花塞井进油史
  - 期望：热怠速 Adapt 从约 +4% 回到近 0；Integrator 不再长期 +8% 以上；怠速油耗下降
  - 对 12.2 L/100km 的贡献：主要吃低速/怠速，市区可能改善约数个百分点，**不是**把油耗打到高速巡航水平

### B 类：可能影响油耗，需先验证

- **进气歧管 / 真空管泄漏**（若气门室盖烟测阴性）
- **驾驶循环**：均速 35.6 km/h 的综合油耗很大一部分是工况，不是故障。补采巡航后再判断「剩余异常」有多大
- **第 4 缸井内是否仍渗油**：影响点火可靠性，间接可能回到失火；当前数据尚未显示持续失火

### C 类：潜在风险，目前不必为油耗处理

- 第 4 缸冷启动单次失火计数（观察，不换件）
- 节温器 / 水温（本次正常）
- 高压油泵 / 喷油能力（本段反证更强，待高负荷数据）
- 涡轮 / 增压管（本段负荷不够）
- VANOS（缺实际角度）
- 更换 MAF 或 Lambda 传感器（形态不符，禁止作为第一步）

禁止根据本报告直接「可能是 XX，建议换 XX」。A 类也是先验证再决定是否更换气门室盖/PCV。

## 5. 下一步采集建议

当前最大限制：只有约 10 分钟市区片段，没有巡航和明确高负荷。

| 缺少什么 | 为什么需要 | 如何采集 |
| -- | -- | -- |
| 60–100 km/h 稳态 ≥5 min | 判断同速负荷是否异常，把「工况油耗」和「泄漏油耗」分开 | 热车后平路定速，保持负荷平稳，5 Hz 即可 |
| BoostTarget | 没有目标值无法说增压偏差 | 在现有通道上增加增压目标 |
| 燃油压力（低压轨 / 高压轨） | 排除高负荷供油不足必须看压力，不能只看 Lambda | 一次中等加速 + 一次油门较深的加速 |
| 点火角 | 判断爆震/过热点火推迟是否抬油耗 | 与负荷、Knock 一起记 |
| VANOS 实际角 vs 目标角 | PWM 不能代表相位是否跟上 | 热车变负荷时记录 |
| 更长热怠速（30–60 s，关掉自动启停） | 本段热怠速仅 27 个样本，RPM 统计被启停干扰 | 热车 P 挡或 N 挡，关闭 MSA |
| 再一次完整冷启动 | 确认第 4 缸失火是否可重复 | 过夜冷机，从钥匙打火记到ECT 80℃ |
| 瞬时油耗或喷油时间 | 把 Adapt 换成升/小时更直观 | 若 ECU 有 InjTime / FuelRate 一并勾选 |

建议采集顺序：

1. 冷机外观：气门室盖、PCV、火花塞井
2. 热怠速 1 分钟（关 MSA）+ 烟测
3. 同一路线热车再跑，加上一段 80 km/h 定速
4. 若 A 类验证成立，修复后再用同一脚本复跑 `analyze.py`，看 Adapt–负荷曲线是否从类型 1 变平

## 6. 因果链（本次数据能连上的部分）

```
空气：MAF 读数随负荷线性，怠速空气量本身不低
    → 但低负荷出现明显正燃油修正，高负荷修正消失
    → 指向 MAF 之后的未计量空气（PCV/气门室盖/真空）最符合

燃烧：热车 Lambda 能跟目标，无持续失火
    → 燃烧过程本身健康

Lambda 反馈：怠速 Integrator +8.7%，Adapt +4.4%
    → ECU 认为混合气偏稀，正在加浓

喷油策略：怠速 InjQty 约 16 mg/Hub，高于该转速应有水平
    → 补偿是真实多喷油，不是显示值假象

实际油耗：均速约 35.6 km/h 的市区循环
    → 大量时间停在泄漏影响最大的低负荷区
    → 冷启动加浓叠加
    → 综合油耗偏高，且与「高速巡航费油」不是同一机制
```

**结论：** 最可能的可维修原因是 PCV/气门室盖相关真空泄漏。它解释了类型 1 修正、热怠速加浓、怠速偏高，也与火花塞井进油的历史一致。它会抬高市区油耗，但本段没有巡航/高负荷数据，不能把 12.2 L/100km 全部算在这个故障上，更不能据此更换 MAF、油泵或节温器。
